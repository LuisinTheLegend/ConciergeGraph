### 1. Resolução de `session_id` e `owner_token` ligada a `request_context.session` (`interface/mcp_server.py` + `main.py`)

**Estado na instância `GrafoConciergeServer.__init__`:**
- `self._session_ids: weakref.WeakKeyDictionary[Any, str] = weakref.WeakKeyDictionary()`
- `self._session_owners: weakref.WeakKeyDictionary[Any, str] = weakref.WeakKeyDictionary()`

**Helper `_get_request_context(self)`:**
- Acessa `self._mcp._mcp_server.request_context` dentro de `try ... except LookupError: return None`.

**Resolução de `session_id` (`_resolve_mcp_session_id(self) -> str`):**
1. Se `req_ctx is None` ou `getattr(req_ctx, "session", None) is None` (chamada Python fora de request MCP): retorna `"default"`.
2. Se há `session`: dentro de `try ... except TypeError:`:
   - Se `session in self._session_ids`: retorna `self._session_ids[session]`.
   - Caso contrário: gera `sid = uuid.uuid4().hex`, grava `self._session_ids[session] = sid` e retorna `sid`.
3. Se `session` não suportar weakref ou não for hashable (ex.: mock com `__slots__` ou `object()` levantando `TypeError`): captura `TypeError` e retorna `"default"` sem quebrar.
4. Quando o `ServerSession` encerra e é coletado pelo GC, a entrada em `_session_ids` e `_session_owners` é removida automaticamente sem vazamento.

**Resolução de `owner_token` (`_resolve_owner_token(self) -> str`):**
1. **Fora de request MCP** (`req_ctx is None` ou `session is None`): retorna `self._server_ephemeral_token`.
2. **Dentro de request MCP (`session` presente):**
   - Tenta consultar `self._session_owners.get(session)` (com `try ... except TypeError:`). Se encontrado, retorna o token em cache.
   - **HTTP/SSE** (`getattr(req_ctx, "request", None) is not None`):
     - Extrai `request.headers.get("X-Grafo-Agent-Token", "").strip()` se presente e não-vazio (permite reconexão com posse persistente sem depender de `GRAFO_API_KEY` compartilhada entre clientes).
     - Caso ausente, gera segredo efêmero por sessão `secrets.token_hex(32)`.
     - Tenta persistir em `self._session_owners[session]`. Se `TypeError` (mock não-weakref): retorna o header se fornecido ou faz fallback para `self._server_ephemeral_token` (evitando token aleatório diferente a cada chamada no mesmo mock).
   - **`stdio`** (`getattr(req_ctx, "request", None) is None`):
     - Lê `os.environ.get("GRAFO_AGENT_TOKEN", "").strip()`; se não-vazio, usa-o; senão gera `secrets.token_hex(32)` por sessão (ou `self._server_ephemeral_token` se `session` levantar `TypeError` no `WeakKeyDictionary`).
   - **Redação de segredos (`main.py:103`)**: incluir `"GRAFO_AGENT_TOKEN"` na tupla de `redact_log_secrets` junto a `GRAFO_LLM_API_KEY`, `GRAFO_API_KEY` e `GEMINI_API_KEY`.

**Wrappers MCP vs Funções Standalone (`interface/mcp_server.py`):**
